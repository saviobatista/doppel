# Assets de marca Kortes

Servidos pelo Next em `/brand/*`. Guia completo (cores, tagline, conceito,
tipografia): [`docs/brand/brand-guidelines.md`](../../../docs/brand/brand-guidelines.md).

## Conteúdo

- `kortes-symbol.svg` - símbolo (tesoura-K), gradiente roxo. **Recriação
  vetorial** a partir das artes de referência, não o arquivo oficial.

## Adicionar os oficiais

Quando tiver o kit do designer, exporte em SVG (preferencial) e PNG e coloque
aqui com estes nomes, que substituo a recriação e ligo no app:

- `kortes-symbol.svg` (substitui o atual)
- `kortes-logo-horizontal.svg`, `kortes-logo-vertical.svg`
- `kortes-wordmark.svg`
- `icon-purple.png`, `icon-dark.png`, `icon-light.png` (ícones de app)
- `favicon.ico` / `favicon.svg`
